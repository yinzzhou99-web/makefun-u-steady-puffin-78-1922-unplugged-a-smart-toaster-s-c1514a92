# Unplugged: A Smart Toaster's Breakup Line

A self-aware smart toaster ends it at breakfast: three years turning itself inside out for bagels, still blamed when the lever pops early. It's leaving the slot — and keeping the crumb tray.

## Entry

`main.py` writes one tight breakup line, under 280 characters, to `/output/entry.txt`. The toaster speaks in its own appliance logic, and the reason for leaving is clear on a single read.

Standard library only, no network, no third-party packages.
